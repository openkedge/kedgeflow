# KedgeFlow v0.9.0-alpha.2

Experimental alpha software release, November 23, 2026 (America/Los_Angeles).
This is the enterprise-readiness implementation baseline merged to `main`, with
release documentation and version metadata corrections. Independent enterprise
pilot acceptance is **BLOCKED_EXTERNAL_INPUT**; this release creates no approval,
execution authority, production certification or cloud runtime window.

## Changes since v0.9.0-alpha.1

- Rust governance, admission/issuance, gateway, one-shot broker, target guards,
  retained outcomes and original-attempt recovery for named draft profiles.
- Node Agent Adapter, signed records, evidence, retained operation status and
  resource-specific conformance, including PostgreSQL, Terraform and managed drain.
- SQL-only pilot infrastructure manifests, separate Linux/systemd identities,
  protected configuration/preflight, immutable packaging, operational evidence and
  seven-owner acceptance tooling.
- Physical authority/PostgreSQL restore rehearsals, provider/credential rotation,
  denial and fault fixtures, receipt/readiness/incident tooling and runbooks.
- Required exact-source CI without silent qualification skips; fixture ownership,
  executable placement, Docker source closure and pinned dependency repairs.
- Removal of Chrono maintenance debt while retaining timestamp/Cedar behavior via
  locked time 0.3.55 and two fully inventoried dependency patches.
- Bound the existing acceptance-receipt fixture's original-snapshot recapture
  for the observed reservation-read epoch race, alongside its receipt CAS race.
  Target dispatch stays single and runtime refusal behavior is unchanged.
- Correct runtime discovery version and README scope/qualification descriptions.

## Release contents and evidence

The published release attaches the exact-source CI record and verifier output,
the CI-built Linux x86_64 core bundle, its draft dependency SBOM/provenance,
the tracked source archive, bounded software qualification summaries and SHA256SUMS.
The source commit, run/attempt and individual asset digests are recorded alongside
those files. GitHub also supplies tag source downloads.

The runtime bundle has ten packaged executables; additional source tools are not
implicitly standalone binary distributions. No ARM64 binary built from an older
commit is relabeled as this release. The Python demo remains version 0.1.0a1.

Required CI consists of eleven successful jobs and their mandatory steps: MSRV,
Rust, real SQL/etcd, container isolation, Linux accounts/packaging, self-hosted
identity/systemd/rotation/restore, Python 3.11/3.12/3.13, dependency triage and
release-required. Qualification runs in disposable environments; it is not the
retained AWS enterprise deployment or an independent reproduction.

Archive timestamps, paths, modes and ownership are normalized. Repeat packaging
of identical binaries/inputs is distinct from independent source-to-binary build
reproduction, which remains open. Checksums and the internal manifest check byte
integrity. This release supplies no independent publisher signing key/signature.
The CycloneDX inventory is an unsigned draft covering locked Rust and Node inputs;
OS/image packages and full licensing/security review are outside its coverage.

## Guarantee and security boundaries

- PostgreSQL Level A applies only to the registered reservation transaction and
  outcome COMMIT under its exact incarnation/version/fence and writer inventory.
  The shipping driver requires a local Unix socket and kernel peer UIDs.
- Terraform remains Level C with target_atomic:false. Kubernetes controller
  acceptance does not establish physical drain completion.
- Unknown effects retain consumed authority and require original-attempt query;
  they do not authorize mutation retries or state resets.
- The Cedar JSON-template advisory exclusion is source/profile-bound and expires
  December 12, 2026 UTC. It is not a globally patched upstream dependency or an
  independent risk acceptance. Both vendored upstream versions remain audited.
- Independent security review, storage/witness/head/floor and audit custody, SRE
  ownership, independent reproduction and signed owner decisions remain open.
  Actual all-writer/bypass, full native application, deployed recovery/cutover and
  measured operational acceptance have not been completed for the retained pilot.
