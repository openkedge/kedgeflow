\section*{Document Status}
\addcontentsline{toc}{section}{Document Status}
This document proposes a reference architecture and interface contract for consequential-action control planes. Component names and conformance requirements are proposals for discussion, not an adopted industry standard. Conditional properties follow from explicit trust, coverage, and resource assumptions; machine-readable schemas, signed compatibility fixtures, and bounded reference services accompany the source. The verification report distinguishes executed local checks from remaining deployment gates. No cross-vendor interoperability, production certification, commercial benchmark, or comparative efficacy result is claimed. AI-assisted drafting and review have been used; the authors are responsible for validating the final architectural and technical claims.

Version 0.9 is frozen on 6 October 2026. The frozen source, PDF and contract hashes are indexed in \texttt{archive/whitepaper-v0.9/FREEZE.json}. Implementation development proceeds in the Rust repository against this baseline; changes to the paper or its protocol contracts require a new version.
